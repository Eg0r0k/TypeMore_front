## Корни (по именам)

- **B-DICT-1 `empty-quote-registry`** — настоящий play-blocking корень.
  Цитаты живут в PG и появляются там только после ручного
  `quotectl import` (встроенный корпус, 15 817 строк). Ни dev-compose
  бэка, ни прод-compose деплоя импорт не запускают, migrate-oneshot гонит
  только goose. Итог на любом свежем стенде: список пуст, random — 404,
  quote-режим мёртв. Симптом «цитаты не грузятся» — это ОН, и выглядит он
  как разъезд путей, потому что 404 приходит с канонического роута.
  Фикс: импорт становится частью bring-up (one-shot сервис в обоих
  compose после migrate; идемпотентен — «unchanged» на повторе).
- **B-DICT-2 `stack-dead`** (ops, попутно): app-контейнер крашлупился на
  лежавшем postgres («lookup postgres: no such host») — при мёртвом стеке
  нет и словарей. Поднят postgres → сервер ожил. Не код.
- **B-DICT-3 `lang-switch-drops-dict`** (фронт, Stage 3): смена языка при
  мёртвой сети РОНЯЕТ уже загруженный словарь — поле заменяется
  error-стейтом, играть нельзя, хотя валидное тело в кэше. Проверено
  Playwright'ом: switch Russian→French при abort всех запросов → поле
  пустое. Требование: неудачная смена не трогает текущий словарь.
- **B-DICT-4 `no-fnv-verify`** (фронт, Stage 2): скачанное тело не
  верифицируется FNV через ядро против `dictHash` из каталога — битое
  или подменённое тело было бы молча использовано.
- Мёртвый легаси: `public/static/quotes/russian.json` — файл старой
  фронтовой статики цитат, ничем не читается (src/e2e — ноль ссылок).

## Что уже здорово (не трогаем)

- Error-стейт тела словаря на игровой поверхности существует: 500 на
  теле → «не удалось загрузить список слов для russian» + кнопка
  «повторить» (скрин fail-body500). Пустого поля/вечного спиннера нет.
- Заголовки иммутабельности на теле — канон, браузер их уважает
  (повторные загрузки тел в пробах шли из кэша).
- `staleTime: Infinity` + `gcTime: Infinity` на теле и каталоге,
  valibot-парс на обоих ответах, queryOptions-модуль — уже по дизайну.
- Availability-проба цитат (`limit=1`) выключает quote-режим честным
  disabled-тумблером, когда корпуса для языка нет.
